# AntiDoom - Win32 Port

**AntiDoom** — это высокопроизводительный, модернизированный нативный Windows-порт оригинального исходного кода `linuxdoom-1.10`, скомпилированный с помощью MinGW-w64 GCC. Порт реализует настоящий широкоформатный рендеринг без искажений, плавную интерполяцию кадров с неограниченным FPS, вертикальный 3D-обзор мышью, прыжки, автономного ИИ-бота и современные функции управления, полностью сохраняя аутентичную пиксельную ретро-эстетику классического программного рендерера id Software.

---

## Ключевые особенности

- **Настоящий Widescreen (16:9 / 21:9)**:
  - Программный рендеринг в честном формате 16:9 (внутренний холст 856x400) с расширенным горизонтальным углом обзора FOV.
  - Никакого сплющивания или растягивания: изображение заполняет весь экран современных мониторов и ноутбуков.
  - Идеальное центрирование всех элементов интерфейса: главного меню, настроек, экрана окончания уровня (статистика, фоновые арты `INTERPIC` / `WIMAP`), финальных титров, каста персонажей и оверлея паузы (`M_PAUSE`).
  - Статус-бар отцентрирован по центру с чистыми бесшовными каменными боковыми крыльями (`st_wings.h`) без дублирования текста боеприпасов.
  - Возможность выбора между честным Widescreen (`-widescreen`) и классическим форматом 4:3 (`-nowidescreen`) с сохранением пропорций (`-keepaspect`).
  - Фиксация текстур пола и потолка: устранено «плавание» и геометрические искажения плоскостей в широкоформатном режиме.
- **Плавный неограниченный FPS (Uncapped FPS)**:
  - Интерполяция кадров в реальном времени выше классических 35 FPS для безупречно плавной картинки на экранах с высокой герцовкой (60 / 144 / 240 Гц).
  - Мгновенное переключение плавности прямо во время игры клавишей `\`.
  - Встроенный счётчик кадров в секунду (FPS), включаемый клавишей `Backspace`.
- **Полноценный 3D-обзор мышью (Freelook / Mouselook)**:
  - Вертикальное прицеливание вверх и вниз без искажения перспективы.
  - Настройки чувствительности и инверсии сохраняются в конфигурационном файле `.doomrc`.
- **Прыжки (`-jump`)**:
  - Физика прыжка на клавишу `Пробел` с возможностью стрейф-контроля в воздухе.
  - Умная раскладка: при включенном прыжке открытие дверей и активация рубильников автоматически переходит на клавишу `E`.
- **Автономный ИИ-бот (`-bot`)**:
  - Встроенный автономный агент: навигация по графу вейпоинтов с поиском кратчайшего пути Дейкстры.
  - Поиск и подбор ключ-карт для закрытых дверей, нажатие рубильников и прохождение к выходу с уровня (`WP_EXIT`).
  - Тактический бой: трассировка видимости BSP, вертикальное прицеливание в монстров, подбор оружия, стрейф и кайтинг.
  - Переключение между ручным управлением и ботом в любой момент клавишей `F10`.
- **Современный ввод и звук**:
  - Поддержка колёсика и курсора мыши в меню: левый клик — выбор, правый клик — назад.
  - Нативный вывод звуковых эффектов через Windows `waveOut` (11025 Гц, 8 бит).
  - Воспроизведение MIDI-музыки через встроенный секвенсор Windows MCI без задержек.
- **Логирование и краш-репорт**:
  - Автоматическое создание мини-дампа памяти `doom2_crash.dmp` и стека вызовов через `dbghelp.dll` при критических сбоях.
  - Подробный лог инициализации и работы в `antidoom.log`.

## Быстрый запуск

### 1. Графический ланчер (`launcher.exe` / `AntiDoom-Launcher.bat`)
Запустите `launcher.exe` для интерактивной настройки и запуска игры:
- **Двуязычный интерфейс (RU / EN)**: переключение языка в 1 клик кнопкой `[ EN ]` / `[ RU ]` в верхнем правом углу шапки.
- **Умное распознавание WAD**: автоматическое определение The Ultimate DOOM (4 эпизода), DOOM Registered (3 эпизода), DOOM Shareware и DOOM II.
- **Разрешение и режимы экрана**: поддержка Full HD (1080p), 2K, 4K, 16:10, оконного режима, полного экрана и окна без рамок.
- **Пропорции экрана**: переключатель True Widescreen (16:9) / Classic (4:3) с опцией сохранения пропорций (`-keepaspect`).
- **Геймплей**: включение прыжков, обзора мышью, плавного FPS, ИИ-бота, быстрых монстров, выбора сложности (1..5) и быстрого перехода на карту (`-warp`).
- **Поддержка модов (PWAD)**: выбор файлов модификаций через системный диалог обзора.
- Все параметры автоматически сохраняются в `launcher.ini`.

### 2. Готовые BAT-скрипты
- **`AntiDoom-Launcher.bat`** — запуск графического ланчера.
- **`AntiDoom-DOOM2.bat`** — запуск DOOM II: Hell on Earth (`wad\DOOM2.WAD`) с интерактивным выбором разрешения и пропорций экрана.
- **`AntiDoom-Ultimate.bat`** — запуск The Ultimate DOOM c 4 эпизодами (`wad\DOOM1.WAD`).
- **`AntiDoom-DOOM1.bat`** — запуск классического DOOM с 3 эпизодами (`wad\DOOM.WAD`).
- **`AntiDoom-Demo.bat`** — демонстрационный режим с автономным ИИ-ботом.

### 3. Из командной строки
```text
antidoom.exe -iwad wad/DOOM2.WAD -res 1920x1080 -fullscreen -widescreen -keepaspect -jump -mlook
antidoom.exe -iwad wad/DOOM1.WAD -res 1280x720 -window -nowidescreen -keepaspect
antidoom.exe -iwad wad/DOOM2.WAD -bot -window
```

## Управление в игре

| Действие | Клавиши / Управление |
| :--- | :--- |
| **Движение** | `W`, `A`, `S`, `D` или Стрелочки |
| **Прыжок** | `Пробел` (при запуске с ключом `-jump` или включении в ланчере) |
| **Действие / Открыть дверь** | `E` (при включенном прыжке) либо `Пробел` / `E` (в классическом режиме) |
| **Стрельба** | `Mouse1` (Левая кнопка мыши) или `Ctrl` |
| **Обзор (3D Mouselook)** | Движение мыши (включение: `-mlook`, выключение: `-nomlook`) |
| **Включить/выключить ИИ-бота** | `F10` (переключение между ручным управлением и автопилотом) |
| **Плавный FPS (Uncapped)** | `\` (переключение между 35 FPS и неограниченной интерполяцией) |
| **Счётчик FPS** | `Backspace` (отображение текущей частоты кадров) |
| **Пауза** | Клавиша `Pause` (центрированная плашка паузы в широкоформатном режиме) |
| **Меню** | `Escape` — открыть/закрыть меню; колёсико мыши или `W`/`S` — навигация; `Mouse1` — выбор; `Mouse2` — назад |
| **Экран статистики (Intermission)** | `Пробел` или `Mouse1` ускоряют подсчёт очков |

## Справочник параметров командной строки

| Параметр | Описание |
| :--- | :--- |
| `-widescreen` | Включает честный формат 16:9 с расширенным углом обзора FOV (холст 856x400) |
| `-nowidescreen` | Отключает широкоформатный режим, принудительно возвращая классический 4:3 (холст 640x400) |
| `-keepaspect` | Сохраняет правильное соотношение сторон (16:9 или 4:3) с аккуратными чёрными полосами без сплющивания картинки |
| `-res <ШИРИНА>x<ВЫСОТА>` | Задаёт разрешение экрана/окна (например: `-res 1920x1080` или `-res 1280x720`) |
| `-fullscreen` | Запуск в полноэкранном режиме |
| `-window` | Запуск в стандартном оконном режиме |
| `-maximized` | Запуск в развёрнутом окне без рамок |
| `-jump` | Включает механику прыжков на `Пробел` и переназначает действие на `E` |
| `-mlook` / `-nomlook` | Включает или выключает вертикальный обзор мышью |
| `-bot` | Активирует режим автономного ИИ-бота при старте игры |
| `-smooth` | Включает интерполяцию кадров выше 35 FPS |
| `-fastparm` | Ускоренная инициализация игры при запуске |
| `-iwad <файл>` | Путь к основному WAD-файлу (`DOOM2.WAD`, `DOOM1.WAD`, `DOOM.WAD`) |
| `-file <pwad>` | Подключение пользовательских модов и карт |
| `-warp <карта>` | Быстрый переход на уровень (например, `-warp 1` для MAP01 или `-warp 1 1` для E1M1) |

## Автономный ИИ-бот (AI Bot Mode)

В AntiDoom встроен полноценный искусственный интеллект, способный самостоятельно исследовать и проходить уровни:
- **Быстрый старт**: скрипт **`AntiDoom-Demo.bat`** либо ключ `-bot`.
- **Переключение на лету**: клавиша **`F10`** в любой момент переключает контроль между игроком и ботом.
- **Боевая система**:
  - Трассировка линии видимости BSP (`P_CheckSight`);
  - Автоматическое прицеливание по вертикали (`lookdir`) прямо в уязвимые точки врагов;
  - Динамический выбор наиболее эффективного оружия (SSG, Shotgun, Chaingun, Plasma, Rockets);
  - Тактический круговой стрейф и кайтинг контактных демонов.
- **Навигация**:
  - Автоматическое построение графа вейпоинтов по геометрии секторов и дверей;
  - Поиск кратчайшего пути к выходу (`WP_EXIT`) алгоритмом Дейкстры;
  - Поиск и сбор необходимых ключ-карт при обнаружении запертых дверей;
  - Открытие дверей и нажатие рубильников (`BT_USE`);
  - Сбор аптечек, брони и патронов при падении ресурсов.

## Диагностика и устранение неполадок

- **Файл журнала**: файл `antidoom.log` формируется при каждом запуске и содержит этапы загрузки WAD, параметры видеорежима, инициализацию звука waveOut и MCI MIDI.
- **Дамп памяти при сбоях**: в случае непредвиденных ошибок перехватчик исключений создаёт мини-дамп `doom2_crash.dmp` и записывает трассировку вызовов в `antidoom.log`.
- **Английская документация**: см. [README.md](README.md) и [BUILD.md](BUILD.md).
