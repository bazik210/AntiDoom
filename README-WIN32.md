# DOOM II Win32 port

Это рабочий Windows-порт исходников `linuxdoom-1.10` из комплекта оригинального DOOM.

## Запуск

Запустите `DOOM2-Win32.bat` и выберите разрешение. WAD уже лежит в `game/DOOM2.WAD`.

Из консоли:

```text
doom2.exe -res 1920x1080 -window
doom2.exe -res 1280x720
doom2.exe -width 1600 -height 900
doom2.exe -nomlook
```

Игра сохраняет базовые настройки в `.doomrc` рядом с exe.

## Управление

- **Движение**: `W`, `A`, `S`, `D` (или классические стрелочки).
- **Действие / Открыть дверь**: `E` или `Пробел`.
- **Стрельба**: `Mouse1` (Левая кнопка мыши) или `Ctrl`.
- **Обзор**: поворот мыши влево/вправо.
- **Полное 3D (Freelook / Mouselook)**:
  - По умолчанию включен полноценный 3D-обзор мышью (наклон вверх и вниз, как в современных шутерах).
  - При отсутствии захваченной автоприцелом цели пули летят точно по направлению взгляда.
  - Настройка сохраняется в `.doomrc`: `mlook 1` (включено) или `mlook 0` (выключено).
  - Также можно отключить через аргумент командной строки: `-nomlook` (или принудительно включить через `-mlook`).
- **Меню**:
  - `Mouse1` на титульном/демо экране открывает меню, а в меню работает как `Enter` (выбор пункта).
  - Колёсико мыши вверх/вниз и клавиши `W` / `S` позволяют перемещаться по пунктам меню.
  - Клавиши `A` / `D` регулируют ползунки громкости/настроек.
  - `Escape` открывает/закрывает меню, а в оконном режиме также освобождает курсор мыши.

## Сборка из исходников

Для быстрой сборки в 1 клик запустите `build_win32.bat` (требуется MinGW-w64 GCC).

Подробная инструкция по сборке, настройке компилятора, командам PowerShell и ручным флагам GCC находится в [BUILD.md].

## Логирование и отладка

При каждом запуске игры рядом с `doom2.exe` формируется подробный файл журнала `doom2.log`.
В него записываются:
- Название и версия порта (`DOOM II Win32 Port v1.10 (Antigravity Enhanced)`);
- Время запуска и точная дата/время сборки;
- Полная командная строка запуска;
- Список загруженных WAD-файлов (IWAD и PWAD);
- Параметры видеоподсистемы (разрешение окна, режим full/window, холст 320x200);
- Параметры звука (waveOut, MCI MIDI Sequencer, уровни громкости SFX и Music);
- Этапы инициализации подсистем игры (`V_Init`, `M_LoadDefaults`, `Z_Init`, `W_Init`, `R_Init`, `P_Init`, `S_Init`);
- Корректное завершение (`I_Quit`) или диагностика критических сбоев (`I_Error`).

Порт использует оригинальную игровую логику и renderer, а Windows-слой находится в `src/linuxdoom-1.10/i_*_win32.c`.
